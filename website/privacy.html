隐私说明 / Privacy

更新日期 / Updated: 2026-11-10

阅读与笔记 / Reading and notes

文献、笔记、批注、截图与索引默认保存在本机。应用没有强制账户，不自建论文云同步服务，也未加入广告或行为分析 SDK。你可以自行备份应用文献库。

Papers, notes, annotations, captures and indexes are stored locally by default. There is no required account, first-party paper sync service, advertising SDK or behavioral analytics SDK. You can back up your library yourself.

可选联网功能 / Optional network services

元数据查询可能向 Crossref / arXiv 等服务发送文献标识符或标题。主动使用 AI 时，当前提问和有界论文、选区、笔记上下文会发送给你选择的 Provider；联网检索会发送查询词。请同时查看该 Provider 的隐私政策。API Key 保存在 macOS Keychain。本机启动 Codex 并不代表模型离线运行。

Metadata lookups may send identifiers or titles to services such as Crossref / arXiv. When you use AI, your prompt and bounded paper, selection and note context go to your selected provider; online search sends search queries. Review that provider’s privacy policy. API keys are stored in macOS Keychain. Running Codex locally does not mean offline model inference.

更新与官网 / Updates and this site

Sparkle 从本官网读取更新信息，从 GitHub 下载更新。请求会向相应服务器暴露 IP 地址等标准网络信息。应用关闭 Sparkle 系统信息采集，自动检查可在设置中关闭。官网不加载第三方分析脚本；站点及下载服务可能保留常规访问日志。语言选择只保存在浏览器本地。

Sparkle reads the update feed from this site and downloads updates from GitHub. Requests expose standard network information such as IP addresses to those services. Sparkle system profiling is disabled; automatic checking can be disabled in Settings. This page uses no third-party analytics scripts. Hosting and download services may retain standard access logs. The language preference stays in browser local storage.

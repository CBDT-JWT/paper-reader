## 原生界面实际操作

- 启动 `.app`，显示真实 PDFKit 与 Tiptap 三栏工作台。
- 编辑文字，打开公式面板，插入 `E = mc^2`，点击后再次修改为 `E^2 = p^2c^2 + m^2c^4`；渲染与保存正常。
- 用鼠标框选 PDF 曲线，从 PDF 渲染出 1492 × 364 PNG 并插入笔记，生成来源链接。
- 退出并重新启动，关联笔记和截图保留。
- 设置中尝试把导入键改为 Cmd+P，提示系统保留；尝试 Cmd+S，提示与保存笔记冲突；均未应用。
- 从工具栏菜单选择“导出笔记 PDF”，使用原生 NSSavePanel 保存到测试目录，状态显示“笔记 PDF 已导出”。
- 原生 Cmd+W 关闭设置窗口并返回论文工作台；最终 ZIP 已解压并通过 codesign 完整性检查。

## 发现并修复的问题

- Tiptap 的编辑用空尾段落影响结构比较：比较时仅归一化不承载内容的尾段落。
- 数学扩展的更新命令读取位置有特定要求：显式传入节点位置，并通过真实 DOM 编辑与撤销验证。
- 新文献的 undo 栈可能包含上篇内容：每次载入重建 Editor，初始化内容不进入历史。
- 截图矩形没有文字时无法用文字选区反馈：引入独立来源矩形高亮层。
- Foundation 在不存在的末级路径下不能可靠解析中间符号链接：逐级拒绝符号链接和上级路径，补充安全测试。
- WebKit 同步打印无法等待分页：改为允许独立打印线程的异步 modal 操作，并将回调切回 MainActor；导出完整 11 页后验证。
- 同步目录给 `.bundle` / `.app` 添加 Finder 元数据破坏签名：缓存目录构建签名，提供启动软链接和可迁移 ZIP。
- 保存重入/切换可能产生版本竞态：单一保存 worker 持有 revision 过渡，显式同步 WebKit 后再切换、导出或退出。

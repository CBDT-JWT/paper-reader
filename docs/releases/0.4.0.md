Paper Reader 0.4.0 adds folder workspaces and optional iCloud Drive sync for Apple Silicon Macs running macOS 14 or later.

- **Open Folder… / 打开文件夹… (Cmd+Shift+O)** opens existing PDFs in place and preserves the folder hierarchy. The file-tree header and context menu include the same command; dropping a folder also opens it.
- **Settings → Library & iCloud / 设置 → 文献库与 iCloud** connects a selected iCloud Drive folder. A new cloud workspace copies the current library while keeping the original; an existing workspace opens directly. Choose that same folder on another Mac to access its files.
- Papers, Markdown notes, screenshots, source references and annotations live in ordinary shared files. SQLite, reading positions, API keys and AI conversations stay on the current Mac.
- Independent local draft recovery protects edits when a file provider is unavailable. Reopening restores the draft or backs up both changed versions before choosing one. Known cloud placeholders are downloaded rather than overwritten with empty content.
- Rename and move operations retain paper IDs and linked notes. Removing an externally linked paper keeps the original PDF; nonempty source folders are protected.

Download the Developer ID signed, Apple-notarized DMG and drag Paper Reader into Applications, or use **Paper Reader → Check for Updates…**. The app and update feed are signed.

Validated with real native PDFKit/WKWebView sessions in English and Simplified Chinese, independent stores, and an actual iCloud Drive folder on one Mac. Actual multi-Mac concurrent editing and automatic conflict merging are not validated or provided. Wait for uploads before switching devices and keep backups. See the README and docs/ICLOUD_VALIDATION.md for details.

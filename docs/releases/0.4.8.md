# Paper Reader 0.4.8

- PDF 选中文字后显示高亮、问 AI 和摘录操作。问 AI 会在对话区显示独立的原文引用。
- AI 回答的选区支持追问和摘录，摘录保留会话来源并支持笔记撤销。
- 输入框增加清晰边界，修复占位文字与光标起点，处理输入法候选确认和 Shift+Enter 换行。
- AI 可通过 downloadFile 工具将文件保存到工作区相对文件夹，同名文件自动另取名称。
- 全屏顶栏更紧凑，各栏标题和底部状态提示统一对齐。图标背景改为天蓝色。

PDF selection actions, quoted AI questions, answer selection follow-ups and note excerpts, workspace file downloads, native input-method handling, aligned full-screen chrome, and a sky-blue app icon.

Validation completed before testing was stopped at the publisher's request includes 54 core tests, 12 editor tests and 167 English native checks. Subsequent input/layout refinements are built but have not completed a final native regression run.

Paper Reader 0.4.1 fixes persistent folder reopening after an application restart.

- Uses ordinary persistent folder bookmarks for the unsandboxed Developer ID build, avoiding a sandbox-scoped resolution error on relaunch.
- Adds a regression check that launches a separate application process to resolve the stored bookmark. This now runs in the real native workspace tests in both languages.
- Explicitly configures the folder chooser for directory content.
- Retains all 0.4.0 features: existing-folder workspaces, optional iCloud Drive sync, local draft recovery and original-library preservation.

Install this patch instead of 0.4.0. If a saved folder fails to open in 0.4.0, the original library remains available through the recovery screen. No research files are deleted by this correction. See README.md and docs/ICLOUD_VALIDATION.md for use and validation limits.

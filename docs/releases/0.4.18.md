# Paper Reader 0.4.18

- 顶栏“导入论文”菜单支持本地 PDF 和链接导入，新增 arXiv、IEEE、DOI 和 PDF 直链解析。
- 下载完成后验证 PDF，并复制到选中的文件夹。显式本地导入也采用复制流程，同名文件自动编号。
- AI 学术检索支持 Crossref / arXiv，downloadPaper 工具可下载并将论文加入文件树，保留当前阅读上下文。
- IEEE 尝试可访问全文及同 DOI 的公开副本。保存来源 URL、实际下载地址和版本信息。
- 导入窗口提供取消、错误反馈和来源网页入口。顶部加号替换为带文字的导入入口。

按用户要求跳过功能、界面和联网下载测试。执行编译、离线编辑器构建、打包和分发检查，实际下载、权限访问、文件复制及 AI 往返仍待运行验证。

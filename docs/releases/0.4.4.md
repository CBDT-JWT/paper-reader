# Paper Reader 0.4.4

## 中文

- 打开文件夹后，整个工作区共用根目录的一份 Markdown。切换论文保留笔记、光标及撤销历史，新截图和图片存入 assets。
- 原有 Markdown 和相对图片路径原地使用，旧逐篇笔记合并迁移，恢复副本和索引留在本机。
- 批注直接保存到原 PDF，保留第三方注释，支持撤销重做和另存导出。旧批注侧文件验证迁移后移除。
- “询问 AI”移到顶部工具栏，保留图标和文字入口。
- 顶部使用图标蓝色的浅色调，PDF 背景采用中性色。普通面板统一圆角与留白，去除装饰分隔线，窗口和工具栏使用系统控件。

## English

- An opened folder uses one shared root Markdown note and assets. PDF switching preserves the note, selection and undo history.
- Existing Markdown and relative images stay in place. Legacy per-paper notes merge into the shared document, with recovery copies and indexes kept locally.
- Annotations save into the original PDF, retain third-party annotations, and support undo, redo and export. Legacy annotation sidecars are removed after verified migration.
- Ask AI is a labeled action in the top toolbar.
- Light-blue top chrome, a neutral PDF canvas, consistent panel corners and gutters, and native window and toolbar controls refine the flat workspace.

Opening a legacy folder performs a storage migration. Keep the entire workspace together when transferring its PDFs, Markdown and assets.

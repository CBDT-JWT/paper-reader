Paper Reader 0.4.3 improves reading focus and the AI conversation workspace.

- Keyboard and automatic reading retain the exact extracted line identity. Overlapping copyright, footnote and equation font boxes can no longer send the reading anchor back to an earlier line.
- Repeated physical gutters separate adjacent columns even when a PDF assigns both sides the same logical text-line tag.
- Left-column footer text continues into the right-column top. Up reverses the handoff, preserving the centred, soft-edged spotlight.
- Graphic placements, vector diagram labels and continuous figure captions are excluded from reading focus. Context windows stop at graphic boundaries, and a fading camera transition skips the graphic. PDFKit selection ranges keep extracted text aligned with its real page position.
- Expanded AI conversations open in a resizable native drawer alongside notes. Offline Markdown rendering supports emphasis, headings, lists, tables, code, page links and KaTeX.
- Choose Codex, a cloud API or a local HTTP model directly in the conversation. Each provider remembers its model and endpoint. Model menus support catalogue refresh and custom names.
- Codex launch environments include common Node installation paths for Finder launches. Connection failures expose exit codes, pending connections cancel promptly, and retry preserves the original question and any unsent draft.
- Regression coverage includes a generated copyright/footer fixture and an optional read-only external-PDF test through the actual PDFKit reader, repeated arrow actions and automatic playback.

Layout detection remains heuristic. Manual column calibration is available for unusual layouts. Automatic reading requires extractable PDF text. Local HTTP inference uses a separately running model service.

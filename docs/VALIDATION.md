## 实际界面操作

已用原生 UI 自动化操作：启动/退出/重新启动；原有笔记和截图保留；菜单由此前 File/Edit/View 与中文混用，变为系统当前的“文件/编辑/显示/阅读/窗口/帮助”；任务复选框的英文默认辅助标签也已本地化。

开启聚焦后，单击 PDF 行，阅读工具中“锁定阅读行”变为选中；按 Down，再单击解除后恢复未选中。滚动到第二页，聚焦和固定状态仍保持。Esc 可退出。修复了两处暗场失效：可见窗口的绘图层可能没有实际更新，导致遮罩仍透明；高亮不在视口时隐藏遮罩。新增检查同时验证实际遮罩路径和填充，旧实现不能通过、修复后通过；鼠标模式开启和滚动会重新选择可见锚点。扫描页使用几何区域兜底。

界面图标目标统一 30×30，图标菜单隐藏挤占空间的下拉指示器，阅读工具栏按宽度折叠；颜色采用系统语义颜色，去除多余边框。截图接口对本机窗口返回了缩小透视图，且单窗口截图不包含额外整屏遮罩窗口；因此没有将该截图当作整屏合成像素的视觉验收。自动化另外检查了每块实际 NSScreen 对应可见遮罩窗口的完整 frame、非激活/穿透属性、层级、实际 CAShapeLayer 路径和非零填充透明度。这个加强的检查曾在旧图层实现中超时，直接更新独立遮罩层后通过。多显示器热插拔和不同显示器设置仍需人工补测。

此前 Phase 1 已人工验证：公式源码重入、截图拖动及来源、Cmd+P 保留/快捷键冲突提示、原生保存面板导出及重启恢复。本版实际通过新录制框录入 Cmd+P / Cmd+S：分别提示系统保留和与保存笔记冲突，均未改变原绑定。关闭设置返回阅读器，直接点击新增暗场按钮，辅助功能状态变为 selected。已重启到最终修复版本。

## 导出与线程问题

本轮导出包含数学、表格、代码、图片和 Mermaid 的长笔记，PDFKit 重新打开验证 12 页及 `Long paragraph 70`；Core Graphics 生成首页/末页 PNG，并实际目视检查：首页截图、公式、表格可见；末页第 69–70 段完整，无截断。批注 PDF 重新打开验证存在真实 PDFAnnotation，输入 PDF 字节完全不变。

曾在后台序列化 PDFKit 注释图时触发 `PDFAKAnnotationAdaptor dealloc` 主线程警告。改为同一可执行程序的无 UI 辅助进程：注释创建、序列化和销毁均在该进程主线程，读者主进程异步等待。后续完整测试日志不再出现该警告，且实际批注导出检查通过。

## 性能样本与边界

一次完整流程样本：离线编辑器就绪约 342 ms，示例生成/导入/打开约 206 ms，缓存文献切换及笔记加载约 45 ms。报告保留每次实际值。这些不是首像素 signpost，也不是普通论文全量性能基准，不能据此宣称所有 PDF 首屏小于一秒。

未验证：Intel、macOS 14–26、系统深色/减少动态效果完整人工验收；百页扫描件、海量文献库、跨应用拖入、所有快捷输入语法；多显示器热插拔、特殊排版普适性；超长表格/极宽代码/所有 Mermaid 图种；断电、磁盘耗尽、多进程共用文献库；沙盒/App Store/签名公证。扫描页无 OCR；通用网页检索、OpenAlex、独立窗口编辑和图形冲突合并器尚未实现。

# Paper Reader 0.4.5

保留 0.4.4 的共享文件夹笔记、原 PDF 批注和浅色原生界面改进。修复较早 macOS PDFKit 对批注字典键的严格要求，通过内嵌记录识别批注，兼容 PDFKit 序列化时省略标准 /NM 字段的行为，并兼容已由 0.4.4 保存的记录。

Includes the shared folder note, in-file PDF annotations and light native interface refinements from 0.4.4. Fixes annotation serialization on earlier macOS PDFKit versions by identifying owned annotations through their embedded records when PDFKit omits the standard /NM identity. Existing 0.4.4 records remain readable.

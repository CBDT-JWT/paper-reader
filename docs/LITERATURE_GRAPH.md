# 关联文献与期刊 / 会议来源

## 入口与浏览

选择一篇论文，在文件树右键选择“关联文献…”，也可通过文件菜单或阅读区更多菜单进入。统一 CommandRegistry 管理入口，快捷键可在设置中自行配置。

文献图窗口支持 DOI、完整标题及 OpenAlex Work ID 搜索。节点可点击和拖动，空白区域可平移，触控板手势可缩放，“重置视图”恢复布局和视口。右侧显示选中文献的作者、年份、期刊 / 会议、引用次数、摘要及来源链接。在库内具有相同 DOI 的论文可直接打开，“以此为中心”继续探索。

图使用 OpenAlex 返回的 related_works、referenced_works 和引用查询结果。蓝色实线表示引用，虚线表示相关文献，灰色实线表示共同参考文献。共同参考文献至少三篇时建立边，每个节点保留最多两条最强共同参考文献连接。默认最多取 12 篇相关文献、12 篇参考文献和 8 篇引用文献，并对节点去重。节点大小随引用次数变化。

图数据按查询保存在设备缓存。再次打开相同查询可读取缓存，窗口显示数据日期。点击“探索”重新请求服务。标题搜索优先接受规范化后完整包含的标题匹配，匹配失败时可输入 DOI。HTTP 或网络失败会在窗口中显示具体错误并提供重试。

## 文件树胶囊

每篇论文下方的 PDF 标签右侧显示出版来源及年份。例如 Design Automation Conference 的 2024 年论文显示 DAC2024。常用会议和期刊采用明确的简称映射，其他来源使用元数据原名。较长名称在胶囊内截断，悬停显示完整名称。旧文献记录的新增字段为可选值，保持原有文件与记录可读。

导入、打开工作区及保存 AI 连接设置时，应用串行补充缺失来源。先复用 DOI / arXiv 元数据检索，再使用已安装或配置好的 AI Provider。AI 输入包含 PDF 前三页文本，结果必须给出对应页码与可在该页验证的原文摘句。来源简称、出版年份、证据和 AI 来源标记随元数据保存。出版年份独立用于胶囊展示，可保留期刊在线发表等既有年份。后台更新采用预期元数据比较，用户同时修改信息时保留用户新版本。

文件树右键或“文献信息”窗口提供“AI 识别期刊 / 会议”手动刷新。信息窗口显示识别状态、来源标记和原文依据，并保留手动编辑能力。来源无法确认时展示识别状态，已有元数据可继续使用。

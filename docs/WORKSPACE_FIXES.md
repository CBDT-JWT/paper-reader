# 全屏、文件树与 IEEE 聚焦修复验证

2026-11-10，Apple Silicon / macOS 27.3 / Xcode 27 / Swift 6.4。范围为0.2.1 工作台的交互修复。

## 变更

**全屏暗场**：使用不激活的 NSPanel 和系统覆盖层 collection roles，监听全屏过渡及活动 Space 变化，过渡完成后重新显示/定位。保留整屏绘图、鼠标穿透、Esc 退出和应用失活隐藏。覆盖检查现在包含 `isOnActiveSpace`，不再只看 `isVisible`。开发中发现将遮罩挂为文档子窗口会重设其窗口层级；最终保持独立覆盖层。[Apple 的 canJoinAllApplications 文档](https://developer.apple.com/documentation/appkit/nswindow/collectionbehavior-swift.struct/canjoinallapplications)明确说明该行为适用于浮动窗口和系统覆盖层。

**直接入口**：阅读工具栏的“聚焦 / Focus”按钮同时展示 SF Symbol 与文字，启用后有选中状态。窄栏将搜索等收进更多菜单，保留聚焦直接入口。原阅读工具弹出面板保留参数设置，移除重复的开启开关。

**文件树**：替换为 AppKit NSOutlineView，原生控件负责点击/展开/拖动会话及落点。阅读状态变化不再重建行，拖动期间延后数据刷新；祖先从外到内展开，移入空文件夹后能立即看到内容。增加单击新建文件夹入口、附着当前窗口的命名表单、可整行点击展开的文件夹行和空文件夹落点。支持文件夹和论文的独立拖动载荷、嵌套/重命名/移动；禁止循环。组织变更在 LibraryStore actor 内读取最新记录后写入，元数据与阅读状态也只更新对应字段。移除文件夹把直属子项提升到上一级，不删除 PDF、笔记或资源。

**应用图标**：新增 imagegen 生成的论文/笔记图标，保留源 PNG 和完整提示词；用 sips/iconutil 生成 16–1024 像素 ICNS、设置 CFBundleIconFile，并在运行时加载 Dock 图标。没有改动系统图标缓存。

**排序**：新增独立的原始/逻辑文件名字段和旧 manifest 回退。文件名、标题、导入日期分别可选，文件名使用自然排序，支持倒序并持久记忆；各层文件夹名也自然排序。文件名变化不改变 UUID 或内部 `paper.pdf` 存储路径。

**IEEE/矢量图聚焦**：实际检查发现极小尺寸的隐藏 LaTeXiT 文本，以及图中的大量短标签；这些内容会污染原来基于所有行宽度的统计。现在按 PDFKit 字符边界重建物理行，过滤不可见微小文字；正文样本决定栏宽/典型字高，用组内中位位置避免标题连接左右栏。还修复了标题命中范围扩展到下一行的问题，按实际文字框和最近行中心选择。

## 自动化

`./scripts/test.sh`：19 项 Swift、11 项编辑器测试，基础原生集成为中英文各 60 项。新增测试覆盖自然文件名顺序、旧文件名回退、完整组织操作及重启读取、最新元数据/阅读状态保留、实际 NSItemProvider 论文/文件夹拖动处理、NSOutlineView 原生剪贴板写入和阅读状态变化时行对象保持、打包图标读取、图标签/隐藏文字/标题与正文命中、原生全屏三条路径。

另通过 `PAPER_READER_LAYOUT_FIXTURES` 指定只读本地样本清单，在同一真实应用中运行布局回归。清单格式为 `[{"name":"sample","path":"/absolute/paper.pdf","columns":2}]`，检查每份样本前三页。它只执行本地 PDFKit 解析，不将样本发给 AI 或外部服务，也不改写 PDF。

本机用 4 篇现有双栏论文的 12 页验证，包含 IEEE TCAD、IEEE Design & Test 及密集矢量图页。中英文各 72 项检查通过：12 页均识别为双栏、没有不可见 LaTeX 元数据进入布局、抽查的正文聚焦没有跨栏。缓存构建中的单页字符提取/布局约 30–60 ms，非通用性能基准。另用 Poppler 渲染并查看问题首页，确认实际为跨栏标题、作者块与双栏正文；没有通过改变预期栏数绕过失败。

最新机器报告：[英文](workspace-fixes-en.json)、[中文](workspace-fixes-zh-Hans.json)。原有 AI 实际外部连接证据仍见 [此前验证记录](VALIDATION.md)，本轮没有重新请求真实云模型。

## 人工界面检查与边界

已实际操作排序菜单，看到文件名正序 01/02/03 和倒序 29/28/27；新建表单成功建立临时文件夹，右键移除后清理完毕。原 SwiftUI 按钮树的鼠标拖动曾复现为点击打开论文，因此切换原生树并增加剪贴板与行身份回归。原生树启动后确认展示真实可选择行和展开三角形；关于窗口显示新图标及版本 0.2.1 (3)，工具栏聚焦按钮点击变为选中，Esc 恢复未选中。鼠标拖放的完整人工验收仍受本机会话的 Space/Stage Manager 与自动化输入冲突影响，未把数据处理测试当作全部鼠标路径的人工验收。多屏热插拔、不同 macOS 版本、任意复杂 IEEE/矢量图版式仍非全面验收；异常页面可手动指定阅读栏。扫描页保持区域聚焦降级，无 OCR。本轮没有修改用户原始论文和笔记内容。
